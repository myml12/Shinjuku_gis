# 新宿駅構内マップ - MapLibre GL JS Webアプリ

GeoJSONファイルを基に、MapLibre GL JSを使用した屋内マップ表示・ノード選択・経路探索ができるWebアプリケーションです。

## 機能

- **全階層表示**: 1F, B1, B2, B3, B5, B6の全階層データを表示
- **3D表示**: 各階層を異なる高さで3D表示（fill-extrusion使用）
- **レイヤー表示**: Floor, Space, Facility, Link, Nodeの各レイヤーを個別に表示/非表示可能
- **ノード選択**: ノードをクリックして選択し、ハイライト表示と詳細情報を表示
- **経路探索**: 2点間の最短経路をDijkstraアルゴリズムで探索・表示
- **階層切り替え**: 表示する階層を選択可能（現在は全階層表示）
- **3D表示制御**: ピッチ角度を調整して3D表示の角度を変更可能

## 使い方

### ローカルで実行

1. ローカルWebサーバーを起動（CORS対策のため必要）

```bash
# Python 3の場合
python3 -m http.server 8000

# Node.jsの場合
npx http-server -p 8000
```

2. ブラウザで `http://localhost:8000` にアクセス

### WebGLで公開

静的ファイルホスティングサービス（GitHub Pages, Netlify, Vercel等）にアップロードするだけで動作します。

## 操作方法

### ノード選択
- 地図上のノード（青い点）をクリックすると選択され、赤色でハイライト表示されます
- 選択したノードの詳細情報が右側のコントロールパネルに表示されます

### 経路探索
1. 「出発点を選択」ボタンをクリック
2. 地図上で出発点となるノードをクリック
3. 「到着点を選択」ボタンをクリック
4. 地図上で到着点となるノードをクリック
5. 自動的に最短経路が赤い線で表示されます
6. 「クリア」ボタンで経路を消去

### レイヤー表示制御
- 右側のコントロールパネルで各レイヤーのチェックボックスをON/OFFして表示を切り替えられます

### 3D表示
- 「3D表示を有効化」チェックボックスで3D表示のON/OFFを切り替え
- ピッチ角度スライダーで3D表示の角度を調整（0°～85°）
- 各階層は異なる高さ（1階層 = 3m）で表示されます

### 経路探索のトラブルシューティング
- 経路が見つからない場合は、ブラウザのコンソール（F12）でデバッグ情報を確認してください
- グラフの構築状況、ノードの接続状況が表示されます
- 同じ階層内のノード間で経路探索を行うことを推奨します

## 技術仕様

- **MapLibre GL JS**: v3.6.2
- **経路探索アルゴリズム**: Dijkstra
- **座標系**: JGD2011 (世界測地系 緯度経度)

## ブラウザ対応

- Chrome/Edge (推奨)
- Firefox
- Safari

WebGL対応のブラウザが必要です。
